**1. `_get_stack_mode(self, game_state)` (PRE-02):**
```python
def _get_stack_mode(self, game_state):
    """PRE-02: Classify stack depth into deep/medium/shallow/push_fold."""
    bb = game_state["blinds"]["big"]
    if bb == 0:
        return "deep"  # safety: avoid division by zero
    bbs = game_state["stack_size"] / bb
    if bbs >= 40:
        return "deep"
    elif bbs >= 25:
        return "medium"
    elif bbs >= 15:
        return "shallow"
    else:
        return "push_fold"
```

**2. `_detect_situation(self, game_state)` (PRE-06):**
```python
def _detect_situation(self, game_state):
    """PRE-06: Infer preflop situation from call_amount relative to blinds."""
    call_amount = game_state["call_amount"]
    bb = game_state["blinds"]["big"]
    sb = game_state["blinds"]["small"]
    if call_amount == 0:
        return "bb_option"
    elif call_amount == bb - sb:
        return "sb_complete"
    elif call_amount == bb:
        return "rfi"
    elif call_amount < bb * 6:
        return "facing_open"
    else:
        return "facing_3bet"
```

**3. `_is_3bet_hand(self, hole_cards)` (PRE-08):**
```python
def _is_3bet_hand(self, hole_cards):
    """PRE-08: QQ+, AKs -- hands that 3-bet facing an open."""
    r1 = (hole_cards[0] >> 8) & 0xF
    r2 = (hole_cards[1] >> 8) & 0xF
    s1 = (hole_cards[0] >> 12) & 0xF
    s2 = (hole_cards[1] >> 12) & 0xF
    high = max(r1, r2)
    low = min(r1, r2)
    if r1 == r2 and r1 >= 10:      # QQ(10), KK(11), AA(12)
        return True
    if high == 12 and low == 11 and s1 == s2:  # AKs
        return True
    return False
```

**4. `_is_4bet_hand(self, hole_cards)` (PRE-08):**

def _is_4bet_hand(self, hole_cards):
    """PRE-08: AA, KK -- hands that 4-bet facing a 3-bet."""
    r1 = (hole_cards[0] >> 8) & 0xF
    r2 = (hole_cards[1] >> 8) & 0xF

**5. `_preflop_raise_amount(self, game_state, stack_mode)` (PRE-09):**
Compute the raise INCREMENT (amount parameter for engine) based on stack mode.
```python
def _preflop_raise_amount(self, game_state, stack_mode):
    """PRE-09: Calculate raise increment by stack mode.
    Returns the amount parameter for ('raise', amount).
    Engine does: total_to_put_in = call_amount + amount.
    """
    bb = game_state["blinds"]["big"]
    call_amount = game_state["call_amount"]
    stack = game_state["stack_size"]
    if stack_mode == "deep":
        desired_total = int(bb * 2.5)
    elif stack_mode == "medium":
        desired_total = int(bb * 2.2)
    else:  # shallow
        desired_total = int(bb * 2.0)
    # amount is the raise increment above call_amount
    amount = desired_total - call_amount
    if amount < 1:
        amount = 1  # _guard will floor to min_raise
    return amount
```

**6. `_preflop(self, game_state, est_pot)` (PRE-03, PRE-07, core decision tree per D-12):**
The main preflop decision method. Decision tree structure (per D-12, designed for Phase 5 extensibility):

```
1. Extract chen_key and chen_score via _get_chen_key + CHEN_TABLE lookup
2. Get stack_mode via _get_stack_mode
3. Get situation via _detect_situation

4. If stack_mode == "push_fold":
   a. If situation is "bb_option": check (call 0) -- free card
   b. If call_amount >= stack_size * 0.5 (facing a shove):
      - villain_bb = call_amount / bb
      - If CALL_TABLE[chen_key] >= villain_bb: call (all-in)
      - Else: fold
   c. If situation in ("rfi", "sb_complete"):
      - hero_bb = stack_size / bb
      - If SHOVE_TABLE[chen_key] >= hero_bb: raise stack_size (shove all-in)
      - Else: fold (or check if sb_complete with call_amount == 0)
   d. If situation in ("facing_open", "facing_3bet"):
      - Treat like facing a shove: use CALL_TABLE
      - villain_bb = call_amount / bb
      - If CALL_TABLE[chen_key] >= villain_bb: raise stack_size (reshove)
      - Else: fold
   e. Set _was_preflop_aggressor if raising

5. If stack_mode == "shallow":
   a. If situation is "bb_option": check
   b. If call_amount >= stack_size * 0.4 (large bet relative to stack):
      - Use CALL_TABLE (treat as shove decision)
      - villain_bb = call_amount / bb
      - If CALL_TABLE[chen_key] >= villain_bb: raise stack_size (reshove)
      - Else: fold
   c. If situation == "rfi":
      - If SHOVE_TABLE[chen_key] >= (stack_size / bb): raise stack_size (shove)
      - Elif chen_score >= 8: raise with _preflop_raise_amount (2.0x BB)
      - Else: fold
   d. If situation == "facing_open":
      - If _is_3bet_hand(): raise stack_size (3-bet shove)
      - Elif chen_score >= 7: call
      - Else: fold
   e. If situation == "facing_3bet":
      - If _is_4bet_hand(): raise stack_size (4-bet shove)
      - Else: fold
   f. If situation == "sb_complete":
      - If chen_score >= 4: call (complete)
      - Else: fold
   g. Set _was_preflop_aggressor if raising

6. If stack_mode in ("deep", "medium"):
   a. Determine chen threshold based on mode:
      - deep_rfi_threshold = 6  (Chen >= 6 ~ 25.5% of hands)
      - medium_rfi_threshold = 7 (Chen >= 7 ~ 17.8% of hands)
   b. If situation == "bb_option": check (call 0)
   c. If situation == "rfi":
      - threshold = deep_rfi_threshold if deep else medium_rfi_threshold
      - If chen_score >= threshold: raise with _preflop_raise_amount
      - Else: fold
   d. If situation == "sb_complete":
      - If chen_score >= 4: call (complete with wide range)
      - Else: fold
   e. If situation == "facing_open":
      - If _is_3bet_hand(): raise 3x the open (amount = call_amount * 3 - call_amount = call_amount * 2)
      - Elif chen_score >= 5: call (defend wide range in position)
      - Else: fold
   f. If situation == "facing_3bet":
      - If _is_4bet_hand(): raise stack_size (4-bet all-in)
      - Elif chen_score >= 9 and stack_mode == "deep": call (JJ/TT/AKo/AQs level)
      - Else: fold
   g. Set _was_preflop_aggressor if raising

7. All returns go through self._guard(action, amount, game_state)
```
