    **Method 1: _postflop(self, game_state, est_pot)**
    Per D-10: Single entry point for postflop decisions. Computes EHS and texture ONCE (anti-pattern: never call _ehs twice), determines street from len(board), routes to _facing_bet or _bet_or_check. Returns the result of whichever sub-method it calls.

    ```python
    def _postflop(self, game_state, est_pot):
        hole = game_state["hole_cards"]
        board = game_state["board_cards"]
        call_amount = game_state["call_amount"]
        ehs = self._ehs(hole, board)
        texture = self._classify_board(board)
        street = len(board)  # 3=flop, 4=turn, 5=river
        if call_amount > 0:
            return self._facing_bet(game_state, est_pot, ehs, texture, street)
        else:
            return self._bet_or_check(game_state, est_pot, ehs, texture, street)
    ```

    **Method 2: _facing_bet(self, game_state, est_pot, ehs, texture, street)**
    Per D-03 (POST-07): req_eq = call_amount / (est_pot + call_amount).
    Per D-09 (POST-13): SPR = stack / est_pot if est_pot > 0 else 999.0. If SPR < 1.5 and EHS >= req_eq -> shove.
    Per D-04 (POST-08): If EHS >= 0.85 (MONSTER) -> raise. Compute raise_size via _calc_bet_size. Apply stack commitment (D-06/POST-10): if raise_size >= stack * 0.6 -> shove.
    If EHS >= req_eq -> call.
    Else -> fold.
    All returns through _guard().

    **Method 3: _bet_or_check(self, game_state, est_pot, ehs, texture, street)**
    Per D-09 (POST-13): SPR = stack / est_pot if est_pot > 0 else 999.0.
    Per D-02 (POST-06): If street == 3 and _was_preflop_aggressor and EHS >= _cbet_threshold(texture): bet. Apply SPR and stack commitment checks before betting.
    Per D-07 (POST-11): If street == 4 and EHS >= 0.65 (STRONG+): barrel at 66% pot. Apply SPR and stack commitment.
    Per D-08 (POST-12): If street == 5 and EHS >= 0.65 (STRONG+): value bet at 75% pot. Apply SPR and stack commitment.
    Default: check via _guard("call", 0, game_state).
    All returns through _guard().

    **Method 4: _cbet_threshold(self, texture)**
    Per D-02 (POST-06): Returns EHS threshold for c-betting based on board texture.
    DRY -> 0.35 (c-bet wider), SEMI_WET -> 0.45, PAIRED -> 0.40, WET -> 0.55 (tighter).

    **Method 5: _calc_bet_size(self, est_pot, stack, texture, street)**

    Turn (street 4): 66%.
    River (street 5): 75%.
